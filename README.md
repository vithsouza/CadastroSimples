# 📋 Cadastro Simples

Sistema de cadastro desenvolvido em **Java** com o objetivo de praticar os conceitos fundamentais de **Programação Orientada a Objetos (POO)** e manipulação de dados.

O projeto permite realizar operações básicas de cadastro e gerenciamento de informações, servindo como base para o aprendizado de estruturas de software e desenvolvimento de aplicações em Java.

---

## ✨ Funcionalidades

* ➕ Cadastro de registros
* 📄 Listagem dos dados cadastrados
* 🔍 Consulta de informações
* ✏️ Atualização de registros
* ❌ Remoção de registros
* ✔️ Validação básica de entradas

## ▶️ Como Executar

### Pré-requisitos

* Java JDK 17 ou superior
* Uma IDE Java (IntelliJ IDEA, Eclipse ou NetBeans)

### Clone o repositório

```bash
git clone https://github.com/vithoriaCabreira/CadastroSimples.git
```

### Acesse a pasta

```bash
cd CadastroSimples
```

### Compile o projeto

```bash
javac *.java
```

### Execute

```bash
java Main
```

Caso utilize uma IDE, basta importar o projeto e executar a classe principal.
